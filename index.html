Java Basics — Getting Started

▼

📖 Definition:

Java is a popular programming language that runs on many devices. Every Java program needs to be written in a file, compiled (translated into computer language), then run.

💡 Key Concepts:

  • Class Name: Must be exactly the same as your filename — capitalization matters!
  • main() method: This is where your program always starts running.
  • System.out.println(): Command to display text or output on the screen.
  • Compiling: Converts your human-readable code to computer-readable code.

🔧 Commands to Use:

  • Save file: Use the exact same name as your class name
  • Compile: javac FileName.java — checks for errors
  • Run: java FileName — executes your program

💻 Code — HelloJava.java

// Lesson 1: Java Basics
public class HelloJava {
    // main() = where the program starts
    public static void main(String[] args) {
        // Print text to the screen
        System.out.println("Hello from Java!");
        System.out.println("This is my first program!");
    }
}

/* How to use:
1. Save as: HelloJava.java
2. Compile: javac HelloJava.java
3. Run: java HelloJava
*/
02

Variables & Data Types

▼

📖 Definition:

Variables are like containers that store information or data for your program. Data Types tell Java what kind of data you are storing — a number, text, or true/false value.

💡 Common Data Types:

  • int — stores whole numbers only (no decimals). Example: 5, -10, 1000
  • double — stores numbers with decimals. Example: 3.14, 99.99
  • char — stores a single character or letter. Use single quotes: 'A', '3'
  • boolean — stores only two possible values: true or false
  • String — stores text or multiple characters. Use double quotes: "Hello World"

💻 Code — VariablesDemo.java

// Lesson 2: Variables & Data Types
public class VariablesDemo {
    public static void main(String[] args) {
        // int = whole number
        int age = 19;
        System.out.println("Age: " + age);

        // double = decimal number
        double price = 10.50;
        System.out.println("Price: ₱" + price);

        // char = single character
        char grade = 'A';
        System.out.println("Grade: " + grade);

        // boolean = true or false
        boolean isStudent = true;
        System.out.println("Is student? " + isStudent);

        // String = text
        String name = "Bryan";
        System.out.println("Name: " + name);
    }
}
03

User Input with Scanner

▼

📖 Definition:

Scanner is a built-in tool in Java that lets your program read input from the user — whatever the user types on their keyboard becomes data your program can use.

💡 How It Works:

  • Import first: Always write import java.util.Scanner; at the very top of your file
  • Create Scanner: Make a Scanner object to read input
  • Read input: Use methods like nextLine() for text, nextInt() for numbers
  • Close Scanner: Good practice to close it when done

💻 Code — ScannerInput.java

// Lesson 3: Scanner Input
import java.util.Scanner;  // Import the Scanner tool

public class ScannerInput {
    public static void main(String[] args) {
        // Step 1: Create a Scanner object
        Scanner input = new Scanner(System.in);

        // Step 2: Ask and read text input
        System.out.print("Enter your name: ");
        String name = input.nextLine();  // Reads a full line of text

        // Step 3: Ask and read number input
        System.out.print("Enter your age: ");
        int age = input.nextInt();  // Reads a whole number

        // Step 4: Use the input values
        System.out.println("---------------------------");
        System.out.println("Hello, " + name + "!");
        System.out.println("You are " + age + " years old.");

        // Step 5: Close the scanner
        input.close();
    }
}
04

If-Else — Making Decisions

▼

📖 Definition:

If-Else statements let your program make decisions. Based on whether a condition is true or false, the program runs different blocks of code — just like making choices in real life!

💡 Comparison Operators:

  • == — Equal to (not a single = sign!)
  • != — Not equal to
  • > — Greater than
  • < — Less than
  • >= — Greater than or equal to
  • <= — Less than or equal to

💡 Structure:

  • if: Check this condition first — run if TRUE
  • else if: If the first was FALSE, check this one instead
  • else: Run this only when ALL previous conditions were FALSE

💻 Code — GradingSystem.java

// Lesson 4: If-Else / Grading System
import java.util.Scanner;

public class GradingSystem {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        
        System.out.print("Enter your score (0-100): ");
        int score = input.nextInt();
        
        // Check conditions one by one
        if (score >= 90) {
            System.out.println("Grade: A — Excellent! ✅");
        } else if (score >= 80) {
            System.out.println("Grade: B — Very Good! ✅");
        } else if (score >= 75) {
            System.out.println("Grade: C — Passed! ✅");
        } else {
            // Runs only when all above are false
            System.out.println("Grade: F — Needs Improvement.");
        }
        
        input.close();
    }
}
05

Loops — Repeating Actions

▼

📖 Definition:

Loops let you repeat a block of code many times without typing it over and over again. Great for counting, processing lists, or doing tasks multiple times!

💡 Two Main Types:

  • for loop — Best when you know exactly how many times to repeat. Has 3 parts: starting point, ending condition, and increment.
  • while loop — Repeats as long as the condition stays TRUE. Use when you don't know how many repetitions you need.

💻 Code — LoopsDemo.java

// Lesson 5: Loops — For and While
public class LoopsDemo {
    public static void main(String[] args) {
        System.out.println("=== For Loop: Count 1 to 5 ===");
        // (start; condition; change)
        for (int i = 1; i <= 5; i++) {
            System.out.println("Count: " + i);
        }

        System.out.println("\n=== While Loop: Count Down ===");
        int count = 5;  // Starting value
        while (count >= 1) {  // Repeat while condition is true
            System.out.println("Remaining: " + count);
            count--;  // Decrease by 1 each time
        }

        System.out.println("\nDone!");
    }
}
